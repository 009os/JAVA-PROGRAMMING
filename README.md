# JAVA-PROGRAMMING

This repository contains a collection of Java programs covering core concepts, algorithms, and practical examples. It is designed for learners and developers to understand and practice Java programming.

## Features

- Sample programs for beginners and intermediates
- Covers basic syntax, OOP, data structures, and algorithms
- Well-organized code for easy understanding

## Getting Started

1. Clone the repository:
   ```sh
   git clone https://github.com/009os/JAVA-PROGRAMMING.git
   ```
2. Compile and run any Java file:
   ```sh
   javac FileName.java
   java FileName
   ```
